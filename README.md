# Krishiv Seed Project

This repository is initialized locally and ready to publish to GitHub.

## Publish to GitHub

Run these commands from the project root after you create an empty GitHub repository:

```bash
git branch -M main
git remote add origin https://github.com/<your-username>/krishiv-seed.git
git push -u origin main
```

If `origin` already exists, update it instead:

```bash
git remote set-url origin https://github.com/<your-username>/krishiv-seed.git
git push -u origin main
```
