# Phased Development Roadmap

## Phase 1: Foundation

- monorepo scaffold
- auth and RBAC shell
- seasons, godowns, stacks, user masters
- farmer import flow with preview and validation
- crop registration master list/detail

## Phase 2: Intake Core

- intake receipt entry
- lot allocation engine
- audit logging
- inward slip print
- receipt history and detail view

## Phase 3: Reports

- Godown Wise Detail
- Farmer Wise Detail
- Summary
- Daily Intake Register
- Registration Pending vs Received

## Phase 4: Controls and Ops

- override workflow
- quality hold and rejection rules
- dashboard metrics
- lot ledger and stack stock screens

## Phase 5: Extension

- stock transfer
- grading
- packing
- finished goods traceability
- media attachments and weighbridge integration
